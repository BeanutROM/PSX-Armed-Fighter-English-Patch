# Armed Fighter English Patch

An English translation patch for the Japanese PSX release of **Armed Fighter**.
You need your own Japanese game bin/cue set as no game files or copyrighted work is distributed here,

This was translated with the assistance of OpenAI Codex. The text was reviewed and edited by a human where necessary.

The translation methodology sourced as much information about the game laid across the internet and read through the text of the game to establish profiles for the setting and the characters to establish their tone and word choices when applicable.

## Patching manually

Apply the xdelta patch to its matching original bin file.
